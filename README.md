# Sunders
This is a 2D Dungeon crawler demo that is a playable prototype. You find yourself in a dungeon with no recollection of how you got there, you must find a way out. Features a procedurally generated dungeon, 3 different enemies, inventory and looting system, stats and traits and a sanity system. This is release is for testing and feedback.

OBJECTIVES: The objective of the game is to find a way out of the dungeon. Obtain loot to keep yourself alive; equip armour and weapons; keep potions to heal and power up, but also have key items ready to traverse the dungeon. There are special gems that can be found which are required in order to activate the portal on the map.

**CONTROLS:**
- WASD: movement — character moves toward the mouse direction
- Left Shift: sprint
- P: pause the game
- F: interact
- E: equip items
- U: use items
- Scroll: cycle hotbar slots
- Right-click: block (or remove a selected hotbar item)
- Left-click: attack (select items when inventory is open)
- Tab: open equipment and stats UI
- F5: open bug report

HOW TO INSTALL: download the build zip file and then extract it. Once extracted double click to run the game. It is a unity package so it will have the unity icon. To uninstall just delete the package/unzipped folder.

**KNOWN ISSUES:**
- Sprite sorting — assets may appear in front of or behind one another incorrectly
- Enemies walk into or get stuck in corners and objects due to pathfinding limitations
- Inventory bug where items may disappear when inventory is full or the backpack is toggled
- Audio SFX may randomly play or loop unexpectedly during gameplay
